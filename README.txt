JERICO MENDIOLA PORTFOLIO — NETLIFY STATIC SITE

CONTENTS
- index.html: portfolio content and page structure
- styles.css: responsive visual styling
- script.js: mobile navigation and active section state
- netlify.toml: Netlify publish configuration

DEPLOY
1. Extract this ZIP file.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder (the folder containing index.html) into Netlify Drop.
4. Wait for the deploy to finish and open the generated .netlify.app URL.

IMPORTANT PORTRAIT NOTE
The published portfolio's original portrait is referenced at:
https://jerico-mendiola-portfolio.jeibeemendiola.chatgpt.site/jerico-mendiola.jpg
The build environment could not download the image binary, so this version temporarily loads the portrait from the existing site. To make the migration fully self-contained, save that original image as assets/jerico-mendiola.jpg and change the image src in index.html to assets/jerico-mendiola.jpg. The current HTML has a visual fallback if the original image URL becomes unavailable.
